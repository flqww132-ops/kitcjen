# Книга кухни — Telegram Mini App

Рабочая книга су-шефа: ТТК, идеи блюд, оборудование к дозаказу, матрица заготовок.
Обычный сайт без сборки (HTML/CSS/JS), открывается внутри Telegram как мини-приложение
и в любом браузере.

Адрес: **https://flqww132-ops.github.io/kitcjen/** (после включения GitHub Pages).

## Как запустить

### 1. Включить GitHub Pages (один раз)

На бесплатном аккаунте GitHub Pages работает только для **публичного** репозитория. В этом репозитории
только код приложения — ваши ТТК, идеи и фото здесь не хранятся (они в облаке Telegram и на телефоне),
поэтому открыть его безопасно.

1. Репозиторий → **Settings** → внизу **Danger Zone** → **Change visibility** → **Change to public** → подтвердить.
2. **Settings** → **Pages** → **Source**: «Deploy from a branch» → **Branch**: `main`, папка **/ (root)** → **Save**.
3. Через 1–3 минуты приложение будет по адресу **https://flqww132-ops.github.io/kitcjen/**.

### 2. Создать бота и привязать приложение

1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя (например, «Книга кухни») и
   юзернейм, оканчивающийся на `bot` (например, `kniga_kuhni_bot`). Токен, который пришлёт BotFather,
   никому не показывайте — этому приложению он не нужен.
2. **Кнопка меню** (кнопка слева от поля ввода в чате с ботом):
   `/mybots` → ваш бот → **Bot Settings** → **Menu Button** → **Configure menu button** →
   отправьте адрес `https://flqww132-ops.github.io/kitcjen/` → отправьте название кнопки, например `Книга кухни`.
3. **Main Mini App** (кнопка «Открыть» в профиле бота и в поиске):
   `/mybots` → ваш бот → **Bot Settings** → **Configure Mini App** → **Enable Mini App** → отправьте тот же адрес.
4. Откройте чат с ботом → нажмите кнопку меню. Готово.

Если названия пунктов в BotFather немного отличаются — ищите «Menu Button» и «Mini App» в настройках бота.

### Проверка на компьютере

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Вне Telegram данные хранятся только в этом браузере (облака Telegram там нет) — это нормально для проверки.

## Где хранятся данные

| Что | Где |
|---|---|
| ТТК, идеи, оборудование, заготовки, списки | Облако Telegram (CloudStorage) **и** копия на телефоне (IndexedDB) |
| Фото блюд и подачи | **Только на этом телефоне** (сжатые до ~1280px JPEG) |

- Облако Telegram у каждого пользователя своё: повар, открывший бота, видит **свою** пустую книгу,
  а не вашу. Делиться с поварами — кнопками «Поделиться» (ТТК, список заготовок, список к заказу).
- Синхронизация между вашими устройствами (телефон, Telegram Desktop) — по каждой записи: побеждает
  более свежая правка, удаления тоже переносятся.
- Облако режется на куски по 4000 символов (лимит Telegram — 4096 символов на значение и 1024 ключа),
  данные сжимаются. Запись идёт в запасной «слот», и только потом переключается оглавление — если связь
  оборвётся посреди записи, в облаке остаётся прежняя целая версия.
- **Резервная копия** (Настройки): файл с фото или текст без фото. Восстановление — «объединить» или
  «заменить всё».

## Как добавлять ТТК

1. **Вручную** — форма с ингредиентами (брутто/нетто/единица, % отхода считается сам), технологией по шагам,
   подачей, хранением, фото.
2. **Из файла** — Excel (.xlsx, .xls), Word (.docx), PDF с текстовым слоем. Приложение ищет таблицу с колонками
   «Наименование», «Брутто», «Нетто», понимает г/кг, запятые, строки «Итого»/«Выход», разделы
   «Технология», «Подача», «Хранение». Перед сохранением — экран проверки. Не найденное остаётся пустым.
   Сканы и фото не распознаются — для них способ 3.
3. **Вставить из текста** — ответ Claude по фото карты в формате ниже.

### Формат ТТК (текст)

```
=== ТТК ===
Название: Салат «Цезарь» с курицей
Категория: Салаты
Источник: Белуга
Выход: 250 г
Порций: 1
Ингредиенты:
- Филе куриное | 120 | 100 | г
- Соль | | 3 | г
Технология:
1. Филе обжарить на гриле.
2. Собрать салат.
Подача: На плоской тарелке.
Хранение: Не более 1 часа при +2…+6 °C.
Примечания: —
=== КОНЕЦ ===
```

Строка ингредиента: `продукт | брутто | нетто | единица`. Карт можно вставить сколько угодно подряд.
Инструкция для Claude есть прямо в приложении: «Вставить из текста» → «Скопировать инструкцию для Claude».

### Формат идей (текст)

```
=== ИДЕЯ ===
Название: Тартар из печёной свёклы
Категория: Закуски
Статус: идея
Описание: Свёкла, запечённая в соли, с хреном и копчёным желтком.
=== КОНЕЦ ===
```

Подойдёт и простой список: одна строка — одна идея (`Название — описание`).

## Напоминания и таймеры в Telegram

В разделе «Заготовки» у каждой позиции есть норма и время «Сделать к» на каждый день недели,
а также сколько угодно напоминаний (за любое время: дни, часы, минуты, секунды). На «Сегодня»
время можно поменять только на этот день, просроченное подсвечивается. Таймеры — кнопка ⏱.

Сообщения в чат отправляет бот-напоминальщик (папка `bot/`, Cloudflare Workers, бесплатно).
Как подключить — [`bot/README.md`](bot/README.md). Приложение отправляет боту расписание на 2 недели вперёд
и обновляет его при каждом изменении и открытии приложения.

## Устройство кода

```
  index.html            — страница, подключает telegram-web-app.js
  css/app.css           — стили (цвета из темы Telegram)
  js/app.js             — запуск
  js/tg.js              — Telegram: кнопка «Назад», попапы, «поделиться», запрет свайпа
  js/store.js           — данные: схема, миграции, слияние, синхронизация
  js/cloud.js           — CloudStorage с кусками и защитой от обрыва
  js/idb.js, photos.js  — IndexedDB, сжатие фото
  js/reminders.js       — расписание напоминаний и таймеров, связь с ботом
  js/prepcore.js        — общая логика заготовок (нормы, время, остатки)
  js/theme.js           — оформление (светлая/тёмная/авто)
  bot/                  — бот-напоминальщик (Cloudflare Workers)
  js/textfmt.js         — текстовые форматы ТТК/идей и инструкции для Claude
  js/importfile.js      — распознавание Excel/Word/PDF (библиотеки грузятся с CDN только при импорте)
  js/views/*.js         — экраны: ТТК, идеи, оборудование, заготовки, настройки
```

- **Версия схемы данных** — `SCHEMA_VERSION` в `js/store.js`, миграции — в `MIGRATIONS` там же.
  Данные из облака, с другого устройства и из резервной копии проходят через миграции. Если данные записаны
  более новой версией приложения, старая версия их не перезапишет.
- **Справочник продуктов** (`products`): каждый ингредиент ссылается на продукт (`productId`). У продукта уже
  есть поля `price`, `priceUnit`, `currency`, `supplier`, `priceUpdatedAt` — себестоимость добавится без
  переделки данных.
- Внешние библиотеки (только при импорте файла): SheetJS `xlsx@0.18.5`, `mammoth@1.8.0`, `pdfjs-dist@3.11.174`
  с cdn.jsdelivr.net.
- После правок кода увеличьте `?v=` у `css/app.css` и `js/app.js` в `index.html` — Telegram кэширует страницы.
