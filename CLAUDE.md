# Правила для Claude в этом репозитории

«Книга кухни» — Telegram Mini App для су-шефа (статичный сайт без сборки, GitHub Pages) + бот-напоминальщик
в `bot/` (Cloudflare Workers). Пользователь пишет по-русски — отвечай по-русски, простым языком,
без лишних технических подробностей.

## Версии — при КАЖДОМ изменении

Версия приложения — `APP_VERSION` в `js/store.js` (видна в Настройках). Меняй её в каждом изменении, как в iOS:
- мелкая правка, исправление — `1.3.0 → 1.3.1`;
- заметное новое (функция, экран, раздел) — `1.3.1 → 1.4.0`;
- кардинальная переделка — `1.4.0 → 2.0.0`.

Вместе с версией:
- в `index.html` поставь ту же версию во ВСЕ `?v=` (css, `js/app.js` и карта модулей `importmap` — иначе телефон смешает
  старые и новые файлы). Новый файл в `js/` — добавь его в `importmap`;
- допиши запись в `CHANGELOG.md` (сверху, по-русски, коротко: что изменилось для пользователя).

Запись в `CHANGELOG.md` — это и сообщение пользователям: бот раз в 5 минут читает CHANGELOG на сайте и, когда
там появилась новая версия (и сайт уже обновился), сам присылает всем подключённым «🆕 Книга кухни обновилась до X —
что изменилось» с кнопкой «Открыть». Поэтому каждое изменение (и приложения, и бота) — с новой версией и понятной
записью в CHANGELOG: пункты `- …` простыми словами.

Если меняется структура данных — подними `SCHEMA_VERSION` и добавь миграцию в `MIGRATIONS` (`js/store.js`).

## Облако и вход (с 2.0.0)

- Данные и фото хранятся в облаке бота (`bot/`, Durable Object каждого пользователя, SQLite): `/api/sync`
  (записи, слияние «побеждает более новая» по `updatedAt`), `/api/photo/:id`. Облако Telegram — запасная копия текстов.
- Вне Telegram (приложение на экране «Домой» — `manifest.webmanifest`, `sw.js`) вход по коду из 6 цифр:
  `/api/login-code` (только из Telegram) → `/api/login` → ключ устройства (`js/auth.js`). Устройства и выход — `/api/sessions`.
- Проверка: `tests/audit.js` (экраны), `tests/swipe.js` (свайп).

## Порядок работы

- Если пользователь просит «согласуй перед тем как делать» — сначала коротко предложи план и вопросы, жди ответа.
- Проверяй изменения в браузере (Playwright, экран телефона), смотри скриншоты, присылай пару скриншотов.
- После выкладки — полная проверка ЖИВОГО сайта (https://flqww132-ops.github.io/kitcjen/), а не только локальной копии:
  все вкладки, вложенные экраны, окна и меню, прокрутка до низа, длинные названия; автоматически искать наложения,
  обрезанный текст, сдвиг вбок, кнопки под нижней панелью/«+». Размеры: iPhone 14 Pro Max (телефон пользователя,
  светлая и тёмная тема) и iPhone SE. Всё найденное — исправить и проверить ещё раз.
- Коммить и пушь в `main` — сайт обновляется сам через GitHub Pages.
- Когда нужен ответ пользователя — присылай уведомление (PushNotification).
